# Tata Tulis Aksara Jawa

*Prasajan (Javanese Simplified) dan Lawasan (Javanese Traditional)*

**Tim Kongres Aksara Jawa I Yogyakarta**
Dinas Kebudayaan (Kundha Kabudayan) Daerah Istimewa Yogyakarta

---

Selamat datang di panduan digital Tata Tulis Aksara Jawa hasil keputusan **Kongres Aksara Jawa I Yogyakarta 2021** (hasil keputusan ditetapkan 26 Maret 2021). Gunakan menu di sebelah kiri atau kolom pencarian untuk menelusuri pedoman.

## Dua pola tata tulis

| | Prasajan (Simplified) | Lawasan (Traditional) |
| :--- | :--- | :--- |
| **Acuan** | Paugeran Sriwedari 1922 dan Keputusan Tiga Gubernur (KBJ 1996), dengan beberapa penambahan dan pengurangan | Serat Mardi Kawi dan seluruh karakter aksara Jawa pada slot Unicode A980–A9DF |
| **Susunan aksara** | *ha na ca ra ka* (carakan) | *ka kha ga gha nga* (kagangan), menurut warga aksara |
| **Status isi di website ini** | Bab I–II tersedia | Segera |

## Konvensi penulisan di website ini

- **JGST** = *Javanese General System of Transliteration* (transliterasi baku berstandar internasional, hasil Komisi I).
- **PUJL** = *Pedoman Umum Jawa Latin* (transliterasi praktis berstandar nasional).
- Tanda **◌** menandai posisi aksara yang dipasangi. Contoh: **◌꧀ꦏ** adalah pasangan *ka*.
- Catatan berbentuk kotak kutipan bertanda **Catatan editor** adalah tambahan penyusun website, bukan bagian teks asli pedoman.

## Hari Aksara Jawa

Kongres menetapkan **22 Maret** sebagai Hari Aksara Jawa, dan **setiap Kamis Kliwon** sebagai Hari Beraksara Jawa.
