# 3. Penulisan Singkatan dan Akronim

*Tata Tulis Prasajan (Javanese Simplified) — Bab IV*

Singkatan merupakan aksara atau sekumpulan aksara sebagai bentuk pendek dari sebuah atau beberapa kata, dan setiap aksaranya dipisahkan dengan **pada lingsa** (<span class="jw">꧈</span>). Penulisan singkatan bisa menggunakan aksara mahāpraṇa, kecuali beberapa yang masih menggunakan murda sebagai tata prunggu karena sudah menjadi bagian nomenklatur.

Penulisan singkatan dalam aksara Jawa ada dua cara:

## a. Singkatan dengan unsur kata asli Jawa

Ditulis berdasarkan aksara pertama dalam setiap kata.

| Singkatan | Penulisan |
| :--- | :---: |
| HB | <span class="jw">ꦲ꧈ꦨ꧈</span> |
| PB | <span class="jw">ꦦ꧈ꦨ꧈</span> |
| MN | <span class="jw">ꦩ꧈ꦟ꧈</span> |
| PA | <span class="jw">ꦦ꧈ꦄ꧈</span> |
| KPH | <span class="jw">ꦏ꧈ꦥ꧈ꦲ꧈</span> |
| GKR | <span class="jw">ꦒ꧈ꦏ꧈ꦫ꧈</span> |
| RM | <span class="jw">ꦫ꧈ꦩ꧈</span> |

## b. Singkatan dengan unsur kata serapan asing

Ditulis sesuai pelafalannya.

| SMP | <span class="jw">ꦌꦱ꧀꧈ꦌꦩ꧀꧈ꦥꦺ꧉</span> | ès-èm-pé |

> **Catatan editor:**
> - Taling pada contoh (misalnya ꦠꦺ) diketik sesudah aksaranya sesuai Unicode. Di naskah, taling tampil di depan aksara.
> - Kolom **Pelafalan** ditambahkan editor.
> - Tanda akhir singkatan di naskah tidak seragam: sebagian diakhiri pada lungsi (꧉) dan sebagian pada lingsa (꧈), misalnya MTs, UGM, dan UPN. Penulisan di atas mengikuti naskah.
